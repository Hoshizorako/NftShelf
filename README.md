# NftShelf

NftShelf enables real-time data processing and auto-scaling for dynamic NFT data management and asset manager frameworks.

NftShelf is built to be simple and practical, focusing on doing one thing well.

**Why NftShelf?**

- NftShelf enables real-time data processing
- and auto-scaling for dynamic NFT
- data management and asset manager

- php

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftShelf.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
